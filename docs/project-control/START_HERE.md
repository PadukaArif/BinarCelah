# BinarCelah — Project Control Pack

## Installation (no coding required)
1. Download this ZIP.
2. Open your local BinarCelah repository folder (the folder containing `package.json` once the app is initialized; for now it may be empty).
3. Extract this ZIP directly into that repository folder.
4. The Markdown files will be placed under `docs/project-control/`. Do not paste their contents into source code.
5. In Antigravity, open the BinarCelah repository folder. Use the setup prompt provided in ChatGPT to make Antigravity read these documents before any implementation.

## What these files are
These are project instructions and reference documents, not application code. They define product scope, design constraints, architecture direction, execution order, task tracking, and AI collaboration rules.

## Important
- Do not rename or delete these files without approval.
- Do not treat unverified statistics or claims in Figma mockups as facts.
- Do not begin implementation until the current task prompt explicitly authorizes it.
